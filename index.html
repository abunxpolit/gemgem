Sistem Pertidaksamaan Linear Dua Variabel (SPLDV) — Soal 1 s.d. 4

Soal 1 — Buku Tulis Tebal & Tipis
Zaki membeli dua jenis buku tulis (tebal & tipis). Setiap buku tebal berisi 60 lembar, setiap buku tipis berisi 30 lembar. Zaki ingin membeli paling sedikit 20 buku secara keseluruhan dan total halaman paling sedikit 750 lembar. Jika \(x\) = banyak buku tebal dan \(y\) = banyak buku tipis, sistem pertidaksamaan yang sesuai adalah …

Langkah 1 — Batasan jumlah buku

Jumlah seluruh buku minimal 20 buah:

x + y ≥ 20

Langkah 2 — Batasan total halaman

Total halaman minimal 750 lembar:

60x + 30y ≥ 750

Sederhanakan dengan membagi kedua ruas dengan 30:

2x + y ≥ 25

Langkah 3 — Batasan non-negatif

x ≥ 0 ,  y ≥ 0

Kesimpulan

Sistem pertidaksamaan yang benar:

x + y ≥ 20
2x + y ≥ 25
x ≥ 0
y ≥ 0

Mencocokkan dengan pilihan:

  • A. x + y < 20 ; 2x + y ≥ 25 ; x ≥ 0 ; y ≥ 0
  • B. x + y ≤ 20 ; 2x + y ≥ 25 ; x ≥ 0 ; y ≥ 0
  • C. x + y > 20 ; 2x + y ≥ 25 ; x ≥ 0 ; y ≥ 0
  • D. x + y ≥ 20 ; 2x + y ≥ 25 ; x ≥ 0 ; y ≥ 0 ← benar
  • E. x + y ≥ 25 ; 2x + y ≥ 20 ; x ≥ 0 ; y ≥ 0
D
Jawaban yang tepat adalah D
Soal 2 — Sepeda Lipat & Sepeda Mini
Pak Mahatir mempunyai modal Rp 30.000.000. Harga sepeda lipat Rp 1.500.000/unit dan sepeda mini Rp 1.350.000/unit. Kios hanya mampu menampung maksimal 16 unit. Jika \(x\) = unit sepeda lipat dan \(y\) = unit sepeda mini, model matematika yang sesuai adalah …

Langkah 1 — Batasan modal

1.500.000x + 1.350.000y ≤ 30.000.000

Sederhanakan dengan membagi kedua ruas dengan 150.000:

10x + 9y ≤ 200

Langkah 2 — Batasan kapasitas kios

x + y ≤ 16

Langkah 3 — Batasan non-negatif

x ≥ 0 ,  y ≥ 0

Kesimpulan

Model matematika yang benar:

x + y ≤ 16
10x + 9y ≤ 200
x ≥ 0
y ≥ 0

Mencocokkan dengan pilihan:

  • A. x + y ≤ 16 ; 10x + 9y ≥ 200 ; …
  • B. x + y ≤ 16 ; 10x + 9y ≤ 200 ; x ≥ 0 ; y ≥ 0 ← benar
  • C. x + y ≥ 16 ; 10x + 9y ≥ 200 ; …
  • D. x + y ≤ 16 ; 9x + 10y ≤ 200 ; …
  • E. x + y ≥ 16 ; 9x + 10y ≥ 200 ; …
B
Jawaban yang tepat adalah B
Soal 3 — Kue Bika & Kue Putri Salju
Bu Tina akan membuat \(x\) kue bika dan \(y\) kue putri salju. Persediaan: terigu 5 kg, gula 3 kg, margarin 1 kg.
• Kue bika: 3 kg terigu, 1 kg gula, 0,5 kg margarin
• Kue putri salju: 2 kg terigu, 2 kg gula, 0,5 kg margarin
Model matematika yang sesuai adalah …

Langkah 1 — Batasan terigu

3x + 2y ≤ 5

Langkah 2 — Batasan gula

x + 2y ≤ 3

Langkah 3 — Batasan margarin

0,5x + 0,5y ≤ 1

Kalikan kedua ruas dengan 2:

x + y ≤ 2

Langkah 4 — Batasan non-negatif

x ≥ 0 ,  y ≥ 0

Kesimpulan

Model matematika yang benar:

x + 2y ≤ 3
3x + 2y ≤ 5
x + y ≤ 2
x ≥ 0
y ≥ 0

Mencocokkan dengan pilihan:

  • A. x + 2y ≤ 3 ; 3x + 2y ≤ 5 ; x + y ≤ 2 ; x ≥ 0 ; y ≥ 0 ← benar
  • B. x + 2y ≥ 3 ; 3x + 2y ≥ 5 ; x + y ≤ 2 ; …
  • C. x + 2y ≤ 3 ; 3x + 2y ≥ 5 ; x + y ≥ 2 ; …
  • D. x + 2y ≥ 3 ; 3x + 2y ≤ 5 ; x + y ≥ 2 ; …
  • E. x + 2y ≤ 3 ; 3x + 2y ≤ 5 ; x + y ≥ 2 ; …
A
Jawaban yang tepat adalah A
Soal 4 — Kapal Feri Tipe A & Tipe B
Agen perjalanan menggunakan \(x\) unit kapal feri tipe A dan \(y\) unit kapal feri tipe B untuk mengangkut 600 turis dan 60 ton barang. Jumlah kapal yang digunakan tidak lebih dari 14 unit.
• Kapasitas A: 50 orang & 6 ton
• Kapasitas B: 80 orang & 3 ton
Model matematika dari permasalahan ini adalah …

Langkah 1 — Batasan jumlah kapal

x + y ≤ 14

Langkah 2 — Batasan penumpang

50x + 80y ≥ 600

Sederhanakan dengan membagi kedua ruas dengan 10:

5x + 8y ≥ 60

Langkah 3 — Batasan bagasi (barang)

6x + 3y ≥ 60

Sederhanakan dengan membagi kedua ruas dengan 3:

2x + y ≥ 20

Langkah 4 — Batasan non-negatif

x ≥ 0 ,  y ≥ 0

Kesimpulan

Model matematika yang benar:

x + y ≤ 14
5x + 8y ≥ 60
2x + y ≥ 20
x ≥ 0
y ≥ 0

Mencocokkan dengan pilihan:

  • A. x + y ≤ 14 ; 5x + 8y ≥ 60 ; 2x + y ≤ 20 ; …
  • B. x + y ≤ 14 ; 5x + 8y ≥ 60 ; 2x + y ≥ 20 ; x ≥ 0 ; y ≥ 0 ← benar
  • C. x + y ≤ 14 ; 5x + 8y ≤ 60 ; 2x + y ≤ 20 ; …
  • D. x + y ≥ 14 ; 5x + 8y ≤ 60 ; 2x + y ≤ 20 ; …
  • E. x + y ≥ 14 ; 5x + 8y ≥ 60 ; 2x + y ≤ 20 ; …
B
Jawaban yang tepat adalah B
Catatan: Kapasitas bagasi tipe B diambil 3 ton agar cocok dengan bentuk \(2x + y \geq 20\) yang muncul di pilihan jawaban (bentuk yang sangat umum di soal sejenis).
Ringkasan Jawaban: 1.D • 2.B • 3.A • 4.B
Semua langkah sudah dilengkapi dengan penyederhanaan dan penalaran lengkap.
